How to Use the Sensitivity Converter

  1. Choose the source game: Select the game your current sensitivity comes from and enter the in-game sensitivity.
  2. Enter your mouse DPI: Use your actual mouse DPI. The calculator uses it for eDPI and physical cm/360 calculations.
  3. Choose the target game: Select the game you want to switch to. The calculator applies the stored yaw values and shows a converted sensitivity.
  4. Check cm/360: Use the physical 360° distance as a reference for comparing aim feel across games.

Understanding cm/360° and eDPI

How do I convert Valorant sensitivity to CS2?

The calculator uses Valorant yaw 0.07 and CS2 yaw 0.022, so the CS2 result is approximately your Valorant sensitivity × 3.1818 when DPI stays the same.

Does this converter preserve cm/360?

The conversion formula is designed to preserve the physical 360° distance under the yaw values stored by this tool. Different games can still feel different because of FOV, aiming modes, input behavior and other settings.

Can I use it for Fortnite, Roblox or Minecraft?

Yes. The current game list includes Fortnite, Roblox and an approximate Minecraft value. Those results are based on the stored conversion constants and should be treated according to the label shown in the game selector.
