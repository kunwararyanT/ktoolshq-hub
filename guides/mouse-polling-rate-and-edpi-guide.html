Mouse Polling Rate, eDPI and Sensitivity Conversion Explained

Mouse polling rate describes how often a device reports input to the computer. A nominal 1000 Hz rate corresponds to a one-millisecond reporting interval, while 8000 Hz corresponds to 0.125 milliseconds. These are reporting intervals, not a measurement of the full delay from hand movement to pixels on screen.

Polling rate is not total input latency

End-to-end response also depends on the mouse sensor and firmware, USB path, operating system, game input handling, game frame rate, display and other factors. Higher polling rates can increase event-processing work on some systems, but the effect depends on the hardware, software and workload. If a higher setting produces stutters or no noticeable benefit, compare settings on your own system rather than assuming that the maximum number is always best.

What eDPI means

For a single game using the common convention, effective DPI is calculated as mouse DPI multiplied by the in-game sensitivity value. For example, 800 DPI × 1.5 sensitivity = 1200 eDPI. This is a convenient way to compare settings inside games that use the same input scale; it is not a universal cross-game unit because games can use different sensitivity mappings.

What cm/360 describes

Centimetres per 360° is the physical mouse distance needed to rotate a full turn in the game, under the selected settings. It depends on the game's input scale and any relevant mode or zoom settings. Matching the calculated value can make two configurations more comparable, but differences in field of view, acceleration, scoped settings and game mechanics can still make them feel different.

Use the calculators carefully

  1. Check your mouse's configured DPI in its own software.
  2. Enter the current in-game sensitivity and select the correct game in the Sensitivity Matcher.
  3. Read the listed mapping and note when the calculator marks a conversion as approximate.
  4. Apply the result in the target game, then test it in a training range or controlled movement task and adjust to preference.
  5. Use the Mouse Hz & Polling Test as an observation of browser event timing, not as a certified hardware instrument.

Browser test limitations

Browser scheduling, pointer-event coalescing, display refresh, background tabs and operating-system behavior can affect observed intervals. A web test cannot independently certify the physical device's rated report rate. For a more controlled comparison, close other applications, keep the browser focused, repeat several runs and compare with the mouse manufacturer's specifications or a dedicated diagnostic method.

Use calculated sensitivity values as a starting point. If two games expose different controls or input systems, there may not be a perfect conversion from one slider value to another.
