What This Refresh Rate & Polling Test Measures

This page is a browser-based diagnostic rather than a specification lookup. The monitor test uses requestAnimationFrame() to count rendered frames over time, while the mouse test counts pointer-event data received by the page. The values shown are therefore browser-observed measurements, not a laboratory measurement of your entire display or input pipeline.

Monitor refresh rate (Hz)

Refresh rate describes how often a display can refresh each second. A 144Hz panel, for example, has a nominal frame interval of about 6.94 milliseconds. This test checks the rendering cadence the browser observes while the page is visible.

Mouse polling rate (Hz)

Polling rate is the frequency at which a mouse reports movement or position updates. Higher polling rates can produce shorter report intervals, but this page does not measure total end-to-end input latency.

How to Run the Test

  1. Start the test: Click the main button to begin both measurements.
  2. Check the monitor: Keep the page visible and watch the Display Refresh Rate reading for a stable value.
  3. Test the mouse: Move the mouse continuously inside the mouse panel for several seconds, then compare the reported value with your mouse's configured polling rate.
  4. Repeat when needed: For multi-monitor systems, move the browser window to the display you want to inspect and test again.

Why Your Reading May Differ

Browser measurements can vary with operating-system display settings, GPU load, browser behavior, power-saving modes and other work running on the computer.

Mouse polling results can also vary with the mouse firmware, connection type, operating system, browser implementation and whether coalesced pointer events are available.

Use this tool as a quick browser-side check. For a hardware or driver issue, compare the result with your operating-system display settings and the specifications or configuration software supplied by the device manufacturer.

Frequently Asked Questions

Why does my 144Hz monitor show around 60Hz?

Check that the operating system or GPU is configured for the monitor's intended refresh rate, and make sure the browser window is on the display you want to test. Power-saving or browser rendering behavior can also affect the observed result.

How do I get a better mouse polling reading?

Start the test and move the mouse continuously inside the test area for several seconds. A stable wired or wireless receiver connection and a supported browser can make the measurement more consistent.

Does this test measure input lag?

No. It measures browser-observed refresh cadence and pointer-event frequency. It does not measure total mouse-to-photon or end-to-end input latency.

Does hardware acceleration affect the monitor reading?

Rendering behavior can affect browser measurements. Keep the page visible, avoid heavy background workloads and use a current browser when comparing results.

Measurement note

The display result is based on the browser's animation-frame callbacks, and the mouse result is based on pointer events received by the page. Coalesced pointer events are only available in some browsers, so readings should be treated as practical browser-side estimates rather than certified hardware specifications.
